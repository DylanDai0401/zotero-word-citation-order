# Word 引文顺序

适用于 Zotero 10 和 Windows 桌面版 Microsoft Word。[下载 XPI 安装包](https://github.com/DylanDai0401/zotero-word-citation-order/releases/latest)。

1. 在 Zotero 10 桌面端打开「工具 → 插件」，从齿轮菜单选择「从文件安装插件」，选中 `Zotero引文标记.xpi`。
2. 在 Zotero 条目列表右键点击任意列标题，勾选「引文顺序」。点击这列的标题可按编号排序。进入对应项目分类即可查看该分类中的稿件编号。
3. 在 Windows 桌面版 Word 中打开稿件。插件会自动读取当前文档。在 Zotero 引文窗口点击右上角的「✓」后，Word 完成引文写入时，「引文顺序」列立即更新。直接在 Word 中删除或移动引文后，插件会在下一次自动检查时更新编号。

正文和附件各自从 1 开始编号。插件按 Word 文件保存每份稿件的结果，关闭 Word 或重启 Zotero 后都可以查看。文献在多个项目中被引用时，可以在不同项目分类中显示各自的编号。Word 的「Zotero → Refresh」也会更新当前稿件的记录。

插件根据已引条目所在的分类匹配项目。同一分类保存了多份稿件时，打开「工具 → 切换稿件…」可指定显示哪一份。分类无法自动匹配时，可在相应分类中通过「切换稿件…」选中该稿件完成关联。在「我的文库」层级也可以用同一菜单查看已保存稿件。需要从磁盘读取时，选择「工具 → 读取 Word…」并选取 `.docx`。

只有匹配到 Zotero「我的文库」的条目会显示编号。无法匹配的引文保留其原序号，后续编号可以出现跳号。同一处合并引文按字段内的条目顺序编号。插件读取 Zotero 的活动引文字段，支持正文和引用于正文的脚注、尾注。Word 自动读取适用于 Windows 桌面版 Microsoft Word。
